How to use this — which bit goes where, cutting, fitting, mortising

Two bits, two different jobs

Tenon width is the mortise. Enter the diameter of the bit you will cut the mortise with: it is cut in one pass, so the mortise ends up that wide with ends that radius, and the tenon has to match it.

Router bit diameter is whatever is in the router while you cut the tenon. It need not match the mortising bit — the guide profile is computed for it.

So changing the router bit reshapes the guide profile. It does not move the mortise slot, which is set by the tenon's length and width alone.

Cutting the tenon

  1. Print it engraved-face down, profile pointing up. No supports.
  2. Seat it in the template holder.
  3. Push the bearing fully in, against the widest part of the profile.
  4. Cut a tenon and try it in the mortise. It should be too fat.

Dialling in the fit

Bearing depth is measured from the template's free top face. Flush gives the smallest tenon; deeper gives a bigger one.

Always come down onto the fit, never up to it. Withdraw the bearing a little, recut the same tenon, try it again. Repeat until it goes. A tenon that is still too fat can be cut again; one that has gone under size is scrap, because you cannot put wood back.

Nominal is the size you asked for, at mid-depth — a reference point, not where to begin. The Fit Adjustment table below gives every step.

Cutting the mortise from the slot

Only if you ticked Add mortise slot. The slot is the guide — it bounds the cut in both directions, so you do not need stop collars at all.

  1. Fit a bit that matches the mortise width you want — the same diameter you entered as Tenon width. The slot is sized around it.
  2. Turn the stylus around so the stepped-down pin faces the template.
  3. Drop that pin into the slot and cut, running the pin out to the ends of the slot and letting them stop you.

Before you trust the first one

Measure across the guide profile at its base with calipers. Any error there transfers 1:1 to the tenon, and closing that gap is exactly what the taper is for.

Nothing here has cut wood yet. The math reproduces a measured factory template exactly, which is a strong calibration point — not proof.

Derived Geometry

Export

Geometry is written in millimeters. STEP is the clean import path for Fusion 360; STL or 3MF go straight to a slicer. The setup sheet needs nothing but the arithmetic, so it is always available.

Fit Adjustment

Set the bearing depth by how far its edge sits below the template's free top face. Flush = 0. Deeper = bigger tenon. Start fully inserted, against the widest part of the profile, and work down. The first tenon comes out fat on purpose — every step from there removes wood, and you cannot put it back.
